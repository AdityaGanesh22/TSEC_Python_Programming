# Practical 4 – Task 4: Building an Executable File with PyInstaller

## Objective
Learn how to package a Python program into an executable file (.exe) using `PyInstaller`.

## Instructions
1. Choose any program from earlier practicals (e.g., guessing game, word extractor).
2. Save it in `student_code_4_4.py` with a main() function.
3. Install PyInstaller using pip:
   `pip install pyinstaller`
4. Run the following command in terminal:
   `pyinstaller --onefile student_code_4_4.py`
5. After completion, check the "dist" folder. It will contain `student_code_4_4.exe`.
6. Run the executable file directly:
   `./dist/student_code_4_4.exe`

## Example
If `student_code_4_4.py` contains:
```python
def main():
    print("Hello, World!")
```

The executable will print:
`Hello, World!`

## Transition from C to Python
In C, executables are generated by compiling source code with gcc.  
In Python, tools like `PyInstaller` bundle the interpreter and code into a single file.
